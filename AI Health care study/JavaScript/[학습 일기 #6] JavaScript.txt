[학습 일기 #6] JavaScript

지난 HTML, CSS 학습을 통해 웹 페이지의 구조와 스타일을 만들었다면, 
이제는 “웹이 살아 움직이게 만드는 언어”인 JavaScript를 배울 시점이다.
정적인 문서였던 웹 페이지가 JavaScript를 만나면, 
버튼 클릭, 입력 처리, 계산, 애니메이션 같은 ‘동작’을 갖게 된다.
오늘은 JavaScript의 기본 원리를 이해하고, 다양한 실습을 통해 기초를 다져보려 한다.

1. JavaScript란?

JavaScript는 웹 페이지에 동적인 기능을 부여하는 프로그래밍 언어.
브라우저에서 동작하며 다음과 같은 기능을 수행할 수 있다.

버튼 클릭 반응
애니메이션
서버와 데이터 통신 (API 요청)
입력값 계산 및 검증

HTML이 집의 구조, CSS가 인테리어라면
**JavaScript는 집 안에서 사람이 실제로 생활하며 움직이는 ‘동작’**이라고 볼 수 있다.

2. 기본 개념
2.1. 변수 (Variable)

값을 저장하는 "상자" 같은 개념.
변수 선언 방식
let	재할당 가능, 블록 스코프
const	재할당 불가, 가장 많이 사용됨

<br>

2.2. 함수 (Function)

특정 작업을 수행하는 코드 묶음.
→ “어떤 입력을 받아 처리한 뒤 결과를 반환하는 기계”

<br>

2.3. 자료형 (Data Types)

JavaScript는 다양한 자료형을 가지고 있다.

2.3.1. 원시 타입 (Primitive Types)
String: 텍스트(문자열)를 나타냅니다. 따옴표('', "", `)로 감싸서 표현합니다.
Number: 정수, 실수 등 숫자를 나타냅니다. 특정 범위 이상의 큰 정수는 BigInt를 사용합니다.
BigInt: 매우 큰 정수를 표현하기 위한 자료형입니다.
Boolean: 참(true) 또는 거짓(false)을 나타내는 논리 값입니다.
Undefined: 변수가 선언되었지만 값이 할당되지 않은 상태를 나타냅니다.
Null: 값이 없음을 의도적으로 나타내는 '빈' 값입니다.
Symbol: 고유하고 변경 불가능한 값을 만들어주는 자료형입니다. 

2.3.2. 참조 타입 (Reference Type)
Object (객체): 여러 데이터를 구조적으로 묶어서 다룰 수 있는 복합적인 자료형입니다. 배열(Array)이나 함수(Function)도 객체의 일종입니다.

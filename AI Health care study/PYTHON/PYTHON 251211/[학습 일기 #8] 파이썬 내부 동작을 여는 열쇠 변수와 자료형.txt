지난 시간에는 코랩을 활용해 파이썬 코드를 직접 실행해보는 경험을 했다. 
이제는 한 단계 더 들어가서, 파이썬이 데이터를 어떻게 저장하고 다루는지를 알아볼 차례다. 
오늘은 파이썬의 변수와 자료형에 대해 차근차근 정리하며 실습까지 함께 진행해보겠다.

# 1. 변수(Variable)란?
데이터를 저장해두고, 이름표를 붙여, 나중에 그 값을 다시 꺼내 쓸 수 있도록 하는 것.
예를 들어,

```
age = 32
temperature = 36.5
name = "Ariel"
```

이렇게 ```=```를 사용하여 변수에 저장된 값(오른쪽 값)은 아래와 같이 꺼내 쓸 수 있다.

```
print(age) # 32
print(name) #"Ariel"
```

주의해야할 점은, 파이썬은 코드를 위에서 아래로 읽기 때문에,
**값을 저장한 이후에만 사용할 수 있다**는 점이다.
<br>

## 1.1. 문법적으로 지켜야 하는 규칙(위반 시 에러 발생)

### 1.1.1. 숫자로 시작할 수 없음!
```
1name = "홍길동" # ❌ SyntaxError
name1 = "홍길동" # ✔️ 가능
```

### 1.1.2. 공백(스페이스)이 들어갈 수 없음!
```
patient name = "홍길동" # ❌ 에러 발생
patient_name = "홍길동" # ✔️ 가능
```

### 1.1.3. 특수 문자 사용 불가(밑줄```_```은 예외)
```
name$ = "길동" # ❌ Error
_name = "길동" # ✔️ Ok
```

### 1.1.4. 파이썬 예약어는 변수명으로 쓸 수 없음!
ex) ```if```, ```class```, ```def```, ```True```, ```None```, ```for``` 등
```
if = 10 # ❌ SyntaxError
```
<br>

## 1.2. 권장되는 관례(PEP 8 스타일 가이드)
### 1.2.1. PEP 8이란?
파이썬 커뮤니티에서 추천하는 **가독성 높은 코드 작성을 위한 규칙**.
에러가 발생하는 것은 아니지만, 팀 개발이나 협업 시에는 지키는 것이 좋음.

- [자세한 사항은 여기로!](https://peps.python.org/pep-0008/)

### 1.2.2. 필수 규칙

| **관례** | **설명** | **예시** |
|:-----|:-----|:-----|
| **소문자 + 밑줄** | 변수명은 일반적으로 ```snake_case```로 작성 | ```patient_name```, ```blood_pressure``` |
| **대문자로 시작 x** | 클래스명이 아니면 대문자로 시작하지 않음 | ```UserName ❌```, ```user_name ✔️``` |
| **전부 대문자** | **상수를 표현**할 때 사용 | ```MAX_TEMP = 42``` |
| **한 글자 변수는 지양** | 의미 없는 ```a```, ```b```, ```x``` 등은 피함 | ```age```, ```score``` 등 명확하게
| **길더라도 의미 있는 이름** | 변수명은 간결하면서도 의미 있게 | ```t ❌``` → ```temperature ✔️``` |

### 1.2.3. 추가하면 좋은 규칙

✔️ Code lay-out
들여쓰기는 공백 4칸 을 권장하며, 한 줄은 최대 79자까지로 한다
너무 길면 자동 줄바꿈(```\```) 또는 괄호로 감싸 정리한다
함수와 함수 사이에는 빈 줄 2개, 클래스 내부에서는 빈 줄 1개로 구분한다

✔️ Whitespace in Expressions and Statements
- 다음과 같은 곳의 불필요한 공백은 피한다.
대괄호(```[ ]```)와 소괄호(```( )```)안
콤마(```,```), 콜론(```:```)과 세미콜론(```;```) 앞
일반적으로 ```=```의 양 옆에는 공백이 한 칸씩 있어야 하지만,
키워드 인자(keyword argument)와 인자의 기본값(default parameter value)의 ```=```는 붙여 쓴다

- 다음의 경우에는 공백이 필요하다
연산자 앞과 뒤(ex. ```x=10+20 ❌```, ```x = 10 + 20 ✔️)
콤마(```,```), 콜론(```:```)과 세미콜론(```;```) 뒤(ex. ```print(10,20,30) ❌```, ```print(10, 20, 30) ✔️)

✔️ Comments
코드와 모순되는 주석은 존재해선 안되므로 항상 코드에 따라 갱신해야 한다
불필요한 주석은 달지 않는다(ex. 코드를 그대로 반복하는 주석 ❌, why?를 설명하는 주석 ✔️)

### cf) 저장된 값은 어디로 가는가?
변수에 저장된 값은 **메모리(RAM)에 보관**된다.
파이썬은 값을 저장하면, 내부적으로 그 값에 **번호(ID)를 붙여 추적**한다.
```
a = 100
b = a

print(id(a))
print(id(b))
```

```id()```는 **값**이 **어디 저장되어 있는지**를 숫자로 보여주는 함수이며,
위의 예시와 같이 **동일한 값을 여러 변수가 가리키는 경우도 존재**할 수 있다.

# 2. 자료형(Data type)이란?
어제 [파이썬에서 다루는 자료형의 종류](https://velog.io/@jkh3043/학습-일기-7-코랩을-이용하여-파이썬-시작하기OT)에 대해서 기술했었다.

- 주로 사용되는 기본 자료형
| 자료형 | 예시 | 설명 |
|:-----|:-----|:-----|
| ```int``` | 30, -2, 0 | 정수형(나이, 혈압 등) |
| ```float``` | 36.5, 0.0 | 실수형(체온, BMI 등을 소수점까지 표현) |
| ```str``` | "홍길동", "AI 캠프" | 문자열(이름, 진단명 등) |
| ```bool``` | True, False | 참/거짓(질병 여부, 흡연 여부 등) |

<br>

## 2.1. 왜 자료형을 나눠야 하는가?
자료형에 따라 가능한 연산이 다르기 때문. 예를 들면,
```
print("100" + "20") # 문자열 연결 결과: 10020
print(100 + 20) # 숫자형 덧셈 결과: 120
```

> 이와 같이 **자료형에 따라 연산이 다르게 작용**하기 때문에 **적절한 자료형 구분이 매우 중요**하다.

## 2.2. ```type()```함수로 자료형 확인하기
어떤 값이 어떤 자료형인지 궁금할 때 쓰는 함수.
아래와 같이 사용한다.
```
print(type(32)) # <class 'int'>
print(type(36.5)) # <class 'float'>
print(type("Ariel")) # <class 'str'>
print(type(False)) # <class 'bool'>
```

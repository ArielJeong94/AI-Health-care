# 1. colab이란?
구글이 제공하는 무료 온라인 파이썬 개발 환경으로, 설치 없이 브라우저에서 바로 파이썬 코드를 실행할 수 있고, 머신러닝/데이터 분석용 라이브러리가 기본 설치되어 있다는 장점이 있다.

cf) 왜 Visual Studio Code를 설치했는데도 Colab을 쓰는가?
1) VSCode는 "개발 환경"이고, Colab은 "학습 및 실험 환경"이다.
도구	목적	장점	단점
VSCode	실제 개발 환경 구축	확장성 뛰어남, 실무에 가장 가까움, 파일 구조·버전관리(Git) 학습 가능	초보자에게 설정이 조금 복잡
Colab	코드를 가볍게 실습하고 즉시 실행하는 환경	설치 필요 없음, 바로 실행 가능, 셀 기반으로 실험하기 쉬움	복잡한 프로젝트에는 부적합

정리하면, VSCode는 “개발자”, Colab은 “연구자/학생”에 가까운 도구라고 할 수 있다.

## 1.3. colab 기능 및 단축키

| 단축키 | 기능 |
|:------|:--------|
| Ctrl + M, B | 아래에 코드 셀 추가 |

# 2. Python의 자료형(Data Type)

## 2.1. 숫자형(Numeric)
### 2.1.1. 정수(Integer)
**양수, 음수, 또는 0**이 될 수 있는 숫자
### 2.1.2. 실수(Float)
**소수점**이 있는 숫자
### 2.1.3. 복소수(Complex)
**'실수 + 허수'**로 이루어진 숫자
<br>

## 2.2. 문자열(Str)
단어, 문장과 같은 일련의 **텍스트 데이터**. ```''``` 또는 ```""```로 감싸져 있으며, 이 **따옴표 안의 문자들**이 **문자열로 정의**.
<br>

## 2.3. 불리언(Boolean)
**True**와 **False**의 두 가지 값을 갖는 자료형
<br>

## 2.4. 리스트(List)
**다수의 데이터를 저장**하는데 사용. **리스트**에 **포함된 데이터**는 **"요소(Element)"**라고 부르며, 이 요소는 **고유한 위치(Index)**를 가진다. ```[]```를 사용하여 정의하며, **동일한 자료형의 요소**를 가질수도, **다른 자료형의 요소**를 가질 수도 있다. **(요소 변경 가능)**
```
foods = ["김치찌개", "삼겹살", "냉면"]

first_food = foods[0] # "김치찌개"
second_food = foods[1] # "삼겹살"
third_food = foods[2] # "냉면"
```
<br>

## 2.5. 튜플(Tuple)
리스트와 비슷하나 **불변의 데이터 구조**를 지녀 **안정성이 중요한 상황**에 사용된다. ```()```를 사용하여 정의한다. **(요소 변경 불가능)**
```
foods = ("김치찌개", "삼겹살", "냉면")

first_food = foods[0] # "김치찌개"
second_food = foods[1] # "삼겹살"
third_food = foods[2] # "냉면"
```
<br>

## 2.6. 딕셔너리(Dictionary)
**'키(Key)-값(Value)'**가 쌍으로 구성. 키(Key)는 값(Value)을 식별하는 역할을 하며, 유일해야 하므로 **동일한 키 값은 존재할 수 없다**. **요소의 순서는 중요하지 않으며**, ```{}```를 사용하여 정의할 수 있다. ```{(Key) : (Value)}```의 형태.
<br>

## 2.7. 집합(Set)
**중복된 값이 없는 유일한 값**들의 모임. 순서가 없기 때문에 **인덱스로 접근 불가**. 대신, 집합에 특정 값이 포함되어 있는지는 확인할 수 있기 때문에, 교집합, 합집합, 차집합 등을 구할 수 있다. ```{}```를 사용하여 정의한다.
```
foods = {"김치찌개", "삼겹살", "냉면", "냉면"} # 불가능
foods = {"김치찌개", "삼겹살", "냉면"}

print("김치찌개" in foods) # True
print("곱창" in foods) # False
```

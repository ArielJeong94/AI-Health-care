[학습 일기 #9] 코드의 판단력 만들기: 연산자와 조건문

변수와 자료형을 배웠을 때, 우리는 데이터를 ‘저장’하는 법을 익혔다.
하지만 저장만 할 수 있다고 해서 프로그램이 동작하는 것은 아니다.
데이터를 계산하고, 비교하고, 그 결과에 따라 다른 길을 선택하도록 만드는 과정이 필요하다.

바로 그 역할을 하는 것이 연산자와 조건문이다.
오늘은 이 두 개념을 통해, 파이썬이 어떻게 ‘판단’을 내리는지 직접 경험해보자.

***

1. 연산자란?
값을 계산하거나, 비교하거나, 판단할 때 사용하는 기호이다.

<br>

cf) 연산자가 왜 필요할까?
컴퓨터가 "이 사람은 어리다." or "이 과일이 더 비싸다."와 같은 판단을 하기 위해선
숫자나 조건을 연산자로 비교하고, 계산함으로써 논리적으로 접근하는 과정이 필요하다.

<br><br>

1.1. 연산자의 종류

1.1.1. 산술 연산자

| 연산자 | 설명 | 예시 |
|:-------|:-------|:-------|
| ```+``` | 더하기 | ```100 + 20``` → 120 |
| ```-``` | 빼기 | ```180 - 50``` → 130 |
| ```*``` | 곱하기 | ```70 * 2```  → 140 |
| ```/``` | 나누기 | ```100 / 4``` → 25.0 |
| ```//``` | 나눈 몫 | ```10 // 3``` → 3 |
| ```%``` | 나눈 나머지 | ```10 % 3``` → 1 |
| ```**``` | 제곱 | ```2 ** 3``` → 8 |

* ```/``` vs. ```//```
```/```는 소수점까지 포함한 '실수 나눗셈' 결과물(float)이 출력되고,
```//```는 소수점은 버리고 '정수 몫'(int)만 출력된다.

<br>

1.1.2. 비교 연산자

| 연산자 | 설명 | 예시 |
|:-------|:-------|:-------|
| ```==``` | 같다 | ```10 == 10``` → True |
| ```!=``` | 다르다 | ```10 != 50``` → True |
| ```>``` | 크다 | ```100 > 50```  → True |
| ```<``` | 작다 | ```30 < 50``` → True |
| ```>=``` | 크거나 같다 | ```100 >= 100``` → True |
| ```<=``` | 작거나 같다 | ```90 <= 100``` → True |

<br>

1.1.3. 논리 연산자

| 연산자 | 설명 | 예시 |
|:-------|:-------|:-------|
| ```and``` | 그리고(둘 다 참일 때만 참) | ```True and True``` → True |
| ```or``` | 또는(하나만 참이어도 참) | ```True or False``` → True |
| ```not``` | 아니다(참 ↔ 거짓 뒤집기) | ```not True```  → False |

아래와 같은 상황에서 사용될 수 있다.

```
is_raining = False
has_umbrella = True

print(is_raining and has_umbrella) # 결과: False
print(is_raining or has_umbrella) # 결과: True
print(not is_raining) # 결과: True
```

<br><br>

2. 조건문이란?
상황에 따라 다르게 행동하도록 도와주는 문법.
조건문이 없다면, 상황을 구분하지 못하고 무조건 같은 행동만 하게 된다.
즉, 프로그램이 생각하고 판단하는 능력을 갖게 해주는 용도.

<br>

✅ 조건문을 사용한 올바른 예시

```
age = 17

if age >= 19:
    print("주류를 판매합니다.")
else:
    print("죄송합니다. 나이가 확인되지 않아 판매할 수 없습니다.")

# 결과: 죄송합니다. 나이가 확인되지 않아 판매할 수 없습니다.
```

<br><br>

2.1. 파이썬 조건문 사용법

```
age = 17

if age >= 20:
    print("성인입니다.")
elif age >= 14 and age <= 19:
    print("청소년입니다.")
else: 
    print("어린이입니다.")
```

(1) 먼저 ```if```문을 해석했을 때, 'False'이기 때문에 아래 조건으로 넘어간다.
(만약, 조건이 참인 경우에는 바로 아래 '성인입니다'만 출력된다.)
(2) 'age >= 14'도 'True', 'age <= 19'도 'True'이기 때문에(and로 묶여있어서 둘 다 참이어야 함) '청소년입니다'가 출력된다.
(* JavaScript에서의 조건문과는 차이가 있음! 주의!!)
(3) ```else:```는 위의 모든 조건이 False인 경우에만 마지막으로 실행된다.

<br>

꼭 기억해야할 문법 포인트
조건문 끝에는 콜론(```:```)을 꼭 붙여야 한다(* JavaScript에서의 조건문과는 차이가 있음! 주의!!)
조건이 참일 때 실행될 코드는 한 칸 들여쓰기(보통 스페이스 4칸. * PEP 8 스타일 참고)를 하고 적는다
